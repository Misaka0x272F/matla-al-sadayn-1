# front-copyright（مشخصات کتاب，p15）

- 图书馆著录页（سرشناسه/عنوان/مشخصات نشر/مشخصات ظاهری/فروست/شابک/یادداشت/موضوع/ردهبندی/شناسه افزوده）。
- 关键事实：作者 ʿAbd al-Razzāq Samarqandī（816–887 ق）；به اهتمام عبد الحسین نوایی；
  ناشر: موسسه مطالعات و تحقیقات فرهنگی / پژوهشگاه علوم انسانی；چاپ اول 1353；
  ج 1 دفتر 1 覆盖回历 704–771（应作 717–771，见下）；ISBN 964-426-042-23100。
- 术语：著录字段名（سرشناسه/موضوع/ردهبندی）、主题词（ایران -- تاریخ -- تیموریان）、
  编者/校订者姓名。回历年份统一折算公元。
- 注意：著录中的年代区间与内容不全一致（`مندرجات` 写 [704-771] 与 [807-850] 等卷次划分），
  系全书多卷著录，译文照录并加译注说明本卷范围。
