# ch07（وقایع 764–766 هجری，p213–233）

- 主线：帖木儿与侯赛因在河中的合作与暗斗；法尔斯穆扎法尔兄弟内争。
- 关键事件：امیر حسین 返 سمرقند、镇压 سربداران（764）；
  فارس/عراق：شاه شجاع 与 شاه محمود 反目；شاه نصرة الدین یحیی 赴 یزد；
  765 大战（محاربه شاه شجاع و شاه محمود）、کرمان 收复与反复；
  766 战事延续、شاه شجاع 出征、取 فارس 王座；آذربایجان/بغداد（سلطان اویس）；
  帖木儿与侯赛因关系转恶之端（به مشورت شیر بهرام）。
- 登场：帖木儿、امیر حسین、شاه شجاع、شاه محمود、دولتشاه、سلطان اویس、شیر بهرام。
- 术语注意：کرمان/فارس 地名与城堡名；兄弟争位人物关系须一致。
- 衔接：承 `ch06`；启 `ch08`（帖木儿—侯赛因短暂和解）。
- 风险：R5/R7。
