## 2. 主要内容与结构

- **体裁：编年体（سالشمار）**——以「وقایع سنه N …（某某年之事件）」逐年记事，
  始于 Abu Saʿīd 即位（717 / 1317），历伊儿汗分裂、楚潘家族（چوپان）、
  因朱（اینجو）、穆扎法尔（مظفر）、萨尔巴达尔（سربدار）、克尔特（کرت）、
  Jalāyir 等割据，至帖木儿（امیر تیمور）与侯赛因（امیر حسین）争衡并即位于撒马尔罕（771 / 1370）。
- **内部层级**：年（`## وقایع سنه …`）→ 条（`### ذکر …` 记某事 / `### حکایت …` 故事 / `### اشاره` 按语）。
- **前置辅文**：编者前言（مقدمه）、作者生平（شرح حال مؤلف）、刊本与抄本述略
  （کیفیت طبع و نسخهها）、抄本著录（مشخصات شماره 2098 / نسخه 2125）、
  作者自撰的华丽序文（دیباچه）。
- **后附**：حواشی نسخ（异文汇编）、数字出版方说明。

## 3. 语言风格

- **古典波斯语骈体（نثر مصنوع）**：对仗、押韵、隐喻密集；序文尤甚。
- **阿拉伯语层**：经训引文（如 `فمن عفا و أصلح…`、《الشوری 41》即古兰 42:40）、
  阿拉伯语诗句与术语；部分引文为阿拉伯字母系。
- **诗体**：`نظم`/`بیت`/`مصرع` 标记的波斯语诗（半联 مصرع）；本电子版把两半联压成一行，
  清洗时按行保留、翻译时按诗行处理。
- **校勘标记**：正文内 `«N»` 注码 + 页底 `N) …` 校记（异文符号 ك/س/ع/ف/ظ）+ 印刷页眉引用。

## 4. 翻译基调（写入术语与风格约定）

1. **忠实 + 雅化**：古典骈体不宜逐词直译；保留叙事信息，中文取史书雅正语体。
2. **回历→公元**：首次出现折算公元，其后可只留回历（统一格式）。
3. **专名统一**：帖木儿/伊儿汗系人名、中亚地名依中文世界史惯例（《史集》《世界征服者史》）
   音译，首现括注原文；`صاحبقران` 主译「君主」/「幸运之主」（与专名 `امیر تیمور` 区分）。
4. **诗体**：以中文诗行/韵文呈现，不与散文混排；难解处加【译注】。
5. **编者注释**：作为编者注随文翻译，与 15 世纪正文区分（可加「编者注：」）。
6. **高难度段落**：译文后加【译注】（说明 + 波斯语原文），详见 `plan.md` §4。
